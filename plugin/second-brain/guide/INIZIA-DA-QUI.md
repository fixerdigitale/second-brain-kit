# Inizia da qui

Scrivi `/second-brain:onboarding`.

Il resto te lo dice Claude: prima un lavoro vero fatto insieme, poi una mappa di quello che hai, poi
al massimo 3 passi per migliorarlo. Puoi fermarti quando vuoi e riprendere con «riprendiamo».

---

*Start here (English): type `/second-brain:onboarding`. Claude answers in the language you write in.*

## Se vuoi sapere prima cosa succede

| Parola | Cosa fa |
|---|---|
| `/second-brain:onboarding` | parte o riparte da dove ti eri fermato |
| `salta` | salta il passo in corso |
| `più piano` / `più veloce` | cambia il ritmo |
| `fermati` (o Esc) | si ferma subito |
| `/second-brain:aiuto <argomento>` | risponde dalle guide, con esempi sul tuo lavoro |

Le guide, se ti va di leggerle:

| Guida | Argomento |
|---|---|
| `01-cartella-di-lavoro.md` | dove stanno le cose, il backup |
| `02-memoria.md` | la memoria, le note dei clienti, «salva in memoria» |
| `03-correzioni.md` | come si insegna a Claude a non ripetere un errore |
| `04-skill.md` | cosa sono le skill, quando crearne una, dove trovarne altre |
| `05-tornare-indietro.md` | sicurezza: copie, Esc Esc, `/rewind`, git |
| `06-modelli-e-consumi.md` | quale modello per quale lavoro, limiti d'uso, contesto |
| `07-google-piu-account.md` | lavorare con più account Google |
| `08-pipeline.md` | i lavori che si ripetono, fino all'automatico |
| `09-aggiornare.md` | come si prendono gli aggiornamenti del pacchetto |
| `10-impostazioni.md` | le impostazioni consigliate, una per una |

Tutto quello che uso io, come opzione, sta nel catalogo della repo del kit (`catalogo/`). Quello che
ho provato e lasciato, con il motivo, sta in `catalogo/scartati.md`.
