# Regole d'oro

Le correzioni più importanti, quelle che Claude deve ricordare sempre. Questo file si carica a ogni sessione, quindi va tenuto corto: **massimo 20 righe**, una regola per riga.

Una regola entra qui solo se l'hai detto tu: Claude lo propone quando la stessa correzione arriva due volte, o quando un errore costa soldi o un cliente. Il dettaglio di ogni regola sta nel suo file in questa cartella.
