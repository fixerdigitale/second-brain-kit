# Security

🇮🇹 *Italiano più sotto.*

## Reporting a problem

If you find a security problem in the kit (a script, a hook, a package, the onboarding), please don't open a public issue. Use GitHub's private channel instead: on the repo page, **Security → Report a vulnerability** (private vulnerability reporting). Only I see the report.

Useful things to include:
- which file or package, and the version of the kit (`VERSIONE` file or `CHANGELOG.md`);
- your operating system and Claude Code version;
- the steps to reproduce it, on fake data.

Don't include real keys, passwords or whole logs: if a key has already ended up somewhere, change it at the source first.

## What to expect

I maintain the kit on my own, in my spare time, without guarantees. I read every report and I'll try to answer and fix what I can, but I can't promise response times. When a fix is out, I write it in `CHANGELOG.md`.

## Scope

- In scope: the files in this repository (plugin, scripts, hooks, packages, onboarding texts).
- Out of scope: Claude Code itself and third-party tools mentioned in the cards. Report those to their maintainers.

The scripts and hooks run on your computer with your permissions: read them before installing them.

# Sicurezza

## Segnalare un problema

Se trovi un problema di sicurezza nel kit (uno script, un hook, un pacchetto, l'onboarding), non aprire una issue pubblica. Usa il canale privato di GitHub: sulla pagina della repo, **Security → Report a vulnerability** (segnalazione privata delle vulnerabilità). La segnalazione la vedo solo io.

Cose utili da scrivere:
- quale file o pacchetto, e la versione del kit (file `VERSIONE` o `CHANGELOG.md`);
- il tuo sistema operativo e la versione di Claude Code;
- i passi per riprodurlo, su dati finti.

Non mettere chiavi, password vere o log interi: se una chiave è già finita da qualche parte, prima cambiala alla fonte.

## Cosa aspettarsi

Il kit lo mantengo da solo, nel tempo libero, senza garanzie. Leggo ogni segnalazione e provo a rispondere e a correggere quello che posso, ma non posso promettere tempi di risposta. Quando esce una correzione, la scrivo in `CHANGELOG.md`.

## Cosa riguarda

- Riguarda: i file di questa repository (plugin, script, hook, pacchetti, testi dell'onboarding).
- Non riguarda: Claude Code e gli strumenti di terzi citati nelle schede. Quelli vanno segnalati a chi li mantiene.

Script e hook girano sul tuo computer con i tuoi permessi: leggili prima di installarli.
