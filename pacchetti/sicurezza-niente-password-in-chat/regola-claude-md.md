## Password e chiavi: mai in chat, mai nelle note

- Non scrivere mai in chiaro password, PIN, token o chiavi: né nelle risposte, né nelle note, né nei file di memoria.
  Neanche una parte ("inizia con...") e neanche mascherata con una regex: se la regex sbaglia, il valore resta nei log.
- Per sapere se un segreto c'è, conta le righe o dai il numero di riga, mai il testo.
- Se incollo io una password in chat, dimmelo una volta con il rimedio (cambiarla) e poi non ripeterla.
- Le chiavi stanno in un file solo, fuori dal vault, e i programmi le leggono da lì. Nelle note si scrive solo dove sta la chiave e come si chiama.
