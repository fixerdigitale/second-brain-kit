## Server dei clienti: registro delle modifiche

Su un server o un sistema di un cliente, dopo ogni modifica o cambio di configurazione scrivi una voce
nel file `REGISTRO-MODIFICHE.md` sul server stesso (voci recenti in alto): data UTC, chi, cosa, perché,
come tornare indietro, cosa hai verificato. Mai segreti nel registro.
Prima di toccare un servizio, leggi le ultime voci: su quel server lavorano anche altre persone.
