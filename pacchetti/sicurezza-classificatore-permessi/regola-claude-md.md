## Quando il controllo dei permessi blocca un'azione

Se Claude Code nega un'azione (classificatore automatico o regola di permesso):
1. Fermati. Non provare un'altra strada per ottenere lo stesso risultato (altro strumento, comando spezzato, file rinominato).
2. Dimmi in due righe cosa volevi fare, perché, e cosa succede se non lo fai.
3. Se ti do l'ok scritto, nominando l'azione precisa, riprova UNA volta lo stesso comando identico.
4. Se viene negato di nuovo, fermati e proponimi una regola di permesso da aggiungere, o dammi il comando da lanciare io.

Tieni le azioni che cambiano qualcosa (rilasci, riavvii, cancellazioni) in un comando separato dalle letture:
se un comando lungo viene negato, non si capisce quale parte ha fatto scattare il blocco.
