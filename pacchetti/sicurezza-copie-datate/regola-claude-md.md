## Copie datate prima di modificare

Prima di modificare un file di configurazione importante (settings.json, file di automazioni,
config di un server, un documento lungo che non sta sotto git) fai una copia accanto con la data:
`nome.estensione.bak-AAAAMMGG-nota` (per esempio `settings.json.bak-20261127-permessi`).
Non sovrascrivere mai una copia esistente: aggiungine una nuova.
Dopo la modifica, scrivi nel messaggio il nome della copia, così so da dove tornare indietro.
