# Prova di ripristino

`checklist-prova-ripristino.md`: la lista da seguire una volta al mese per riaprire davvero un backup.

## Dove si copia

Nel vault, per esempio `<cartella-vault>/procedure/checklist-prova-ripristino.md`. Ogni volta fai una copia con la data (`prova-ripristino-AAAAMMGG.md`) e la compili: diventa lo storico delle prove.

## Come si prova

Seguila la prima volta con Claude Code accanto: «segui la checklist di prova di ripristino sul backup di due giorni fa, in una cartella a parte».

## Come si toglie

È un file: cancellalo. Se usi un promemoria mensile in calendario, togli anche quello.

## English

A restore-test checklist: download the backup again as if the computer were lost, decrypt and extract it in a separate folder, then check specific things (files present, main memory file identical, key folders there, configuration opens, password findable without this PC).

Install: copy `checklist-prova-ripristino.md` into your vault and fill in a dated copy at every test: once right after setting up the backup, then monthly. The first time you can have Claude Code walk you through it.
