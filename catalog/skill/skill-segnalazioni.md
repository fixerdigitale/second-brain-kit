# Reports from the browser with a picture of the page

**The problem.** Explaining in words an error on a page or in a spreadsheet ("the button at the bottom right, the blue one") was slow and often wrong.

**How I solved it.** A browser extension: I mark the page with numbered rectangles and arrows, write the note and send. It reaches the server as a task, with picture, address, selected text and, for each mark, the element underneath (text, link, id, source file if the page says so). A skill gives Claude the commands to pick it up, work on it, close it with a note of what it changed, or reopen it.

**Why this way.** With the element under the mark, Claude finds the spot in the code by searching for the text or the link, without guessing. And no report gets closed without verification on the spot.

**When you need it.** If you often review pages, landing pages or spreadsheets made by others (or by the AI) and send precise corrections.

**When you DON'T need it.** If corrections are few, a marked-up screenshot pasted in chat does the same job. And it's a server system: without an always-on place that receives the reports and keeps the pictures behind a login, it doesn't hold up.

**How to get it.** No package: it's just the idea, because the extension, the receiving service and the picture archive live on a server. On a PC the simple version is a screenshot marked up by hand and pasted in chat.
