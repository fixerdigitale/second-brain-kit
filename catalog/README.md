# Catalog

🇮🇹 [Italiano](../catalogo/README.md)

Everything I use, offered as an option. Each card tells the problem I had, how I solved it, why I did it that way, and when you **don't** need it. There's no right order: take only what solves a problem you already have.

> Everything can run on a PC; a PC isn't always online, a server is. Where a card says "server" I describe how I use it; where it says "PC on", the piece only works while the computer is switched on.

**How to read the columns.** *Runs on*: PC, PC on (the computer has to be on at that time) or server (that's how I use it; on a PC it needs adapting). *Level*: basic, intermediate, advanced. *Package*: ready-to-copy files, when there are any; "card only" means I describe how I do it, without files.

**88 cards** in 8 areas. The cards are available in English (this folder) and Italian (catalogo/); the packages' read-me files are in Italian with a short English section. Claude Code can read and explain any of them for you.

What I tried and let go is in [discarded.md](discarded.md).
